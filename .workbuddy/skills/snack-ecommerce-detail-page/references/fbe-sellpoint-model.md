# FBE 卖点转换模型

> "不分析产品有什么，而分析消费者为什么买。"

## 核心转换链

```
产品卖点 (Feature)
    ↓
消费者利益 (Benefit)
    ↓
情绪价值 (Emotion)
    ↓
页面视觉表达
```

## 案例 1：低糖/无添加

| 层级 | 内容 |
|------|------|
| **Feature（产品卖点）** | 低糖 / 无添加 |
| **消费者真正关心** | 孩子喜欢甜味，但妈妈希望控制糖摄入 |
| **Benefit（消费者语言）** | ❌ 不要写"低糖健康"<br>✅ "甜度刚刚好，孩子喜欢，妈妈更安心"<br>✅ "减少甜味负担的儿童零食选择" |
| **Emotion（情绪价值）** | 安心、放心、满足、负责 |
| **视觉表达** | 孩子开心吃零食（注意广告法：不能出现婴儿则展示产品新鲜度或原材料新鲜，产品放在桌子上）<br>构图：平视构图<br>颜色：自然色、偏暖色<br>场景：居家简约风 |

## 案例 2：进口原料

| 层级 | 内容 |
|------|------|
| **Feature** | 进口原料 |
| **消费者真正关心** | 标准、品质、可靠 |
| **Benefit** | ❌ 不要写"欧洲进口品质"<br>✅ "经过严格筛选的优质欧洲原料"<br>✅ "来自欧洲优质产地的自然风味" |
| **Emotion** | 信任、品质保证 |
| **视觉表达** | 用欧洲地图展示产地区域 |

## 案例 3：0添加

| 层级 | 内容 |
|------|------|
| **Feature** | 0添加 |
| **消费者真正关心** | 吃起来更简单、更放心 |
| **Benefit** | ❌ 不要写"0添加"<br>✅ "配料简单，看得懂"<br>✅ "少一些添加，多一些真实" |
| **Emotion** | 简单、纯粹、真实 |
| **视觉表达** | 展示简单配料、天然食材 |

## FBE 转换检查清单

对每个卖点，必须完成以下转换才可通过：
- [ ] Feature：产品到底有什么？（具体事实）
- [ ] Consumer Truth：消费者真正在乎什么？（深层需求）
- [ ] Benefit：翻译成人话怎么说？（一句话能懂）
- [ ] Emotion：让人产生什么感觉？（安心/满足/信任/放心）
- [ ] Visual：画面怎么表现？（构图/颜色/场景）
