# 零食详情页结构规范

## 核心公式

> 产品大图 + 消费者利益点 + 购买理由 = 首屏公式

## 首屏（第一屏）

### 目标
用户看到后产生：吸引停留（美观、惊艳、清晰、概括）

### 必须出现
- 产品主体
- 核心卖点（一句话）
- 使用场景

### 绝对不能出现
- 大量参数
- 空泛品牌口号（如"品质之选"）
- 只有产品没有消费场景

### 优秀参考品牌
- 三只松鼠、babycare

---

## 第二屏 — 为什么值得买

### 目标
解释为什么值得买、解决什么痛点

### 展示内容
- 产地
- 痛点场景（用品类展示）
- 工艺

### 视觉方式
- 用地图展示产地
- 用场景（如孩子哭闹）展示痛点问题 → 产品解决方案

---

## 第三屏 — 原料 & 成分

### 目标
展示零食里主要成分的新鲜程度

### 视觉方式
- 新鲜的食材特写
- 原料溯源

---

## 第四屏 — 工艺 & 口感

### 目标
让人感受到好吃

### 视觉方式
- 酥脆/松软质感特写
- 工艺步骤可视化

---

## 第五屏 — 建立信任

### 目标
品质证明、消除顾虑

### 展示内容
- 检测报告
- 资质认证
- 生产标准

---

## 第六屏 — 刺激购买

### 目标
最终推动下单

### 展示内容
- 使用场景（家庭/聚会/办公）
- 搭配推荐
- 规格/套餐信息

---

## 通用设计原则

1. **一屏一个核心信息** — 不要贪多
2. **视觉逻辑 = 购买逻辑** — 页面顺序就是说服路径
3. **先情感后理性** — 先用画面打动，再用数据说服
4. **每屏都要有"下一步看下去"的理由**

## 竞品分析框架

### 选品标准

必须选取 **3-5 个**有真实数据支撑的竞品：

| 标准 | 说明 |
|------|------|
| 销量好 | 月销量排名靠前、评价数量多（优先选月销过千的） |
| 页面留存率高 | 详情页内容完整、结构清晰、一看就是用心做的 |
| 主图点击率高 | 主图有创意、差异化明显、不是千篇一律的模板 |

**链接获取优先级高于竞品数量。** 至少 3 个竞品必须附可访问的商品详情页直链（detail.tmall.com / item.jd.com / item.taobao.com）。禁止使用第三方排行榜链接（am10.com、smzdm.com）或内容营销页面（bk.taobao.com）代替。

### 分析维度

对每个竞品详情页，按以下维度拆解，**必须附上可点击的商品详情页直链**：

| 维度 | 分析内容 |
|------|---------|
| 基本信息 | 品牌名、产品名、价格区间 |
| 数据表现 | 月销量、好评率、累计评价数（量化数据） |
| 产品定位 | 他们主打什么？健康？好吃？性价比？传统？ |
| 首屏策略 | 首屏写了什么文案？放了什么画面？主图有什么特点？ |
| 核心卖点表达 | 他们把卖点翻译成了什么消费者语言？用了什么话术？ |
| 视觉风格 | 什么配色？什么摄影风格？什么调性？ |
| 结构安排 | 各屏怎么排的？重点放在第几屏？ |
| 做得好 | 哪里值得学习？（具体到文案或画面，数据好说明经过了市场验证） |
| 做得差 | 哪里可以改进？竞品没做到什么？（我们的机会） |
| 产品链接 | ⭐ 商品详情页直链（detail.tmall.com / item.jd.com），可点击访问。链接无效的标注"待补充" |

分析后必须总结：
- 竞品的"普遍做法"（大家都在干什么）
- 我们的"差异化机会"（我们可以干什么不一样的事）

## 逐屏策划输出模板

### 文案字数规则

- **主文案 ≤ 10 字** — 每屏只传达一个核心信息，用最短的话说清。消费者3秒扫读只记住一句，长了等于没写
- **副文案 ≤ 12 字** — 补充说明主文案，也不能啰嗦
- **辅助文案/标签字数不限** — 用于数据、规格、场景标签等辅助信息
- 文案是删出来的，不是写出来的。超过字数说明提炼不够——继续删

每屏按以下格式输出：

```
### 第X屏：[屏名称]

**核心目标**：（这一屏要达成什么转化目的？一句话说清）

**文案**：
- 主文案：XXX（≤10字，精炼，消费者语言，不要术语）
- 副文案：XXX（≤12字）
- 标签/辅助文案：XXX

**画面描述**：
- 拍什么：（具体画面内容 — 产品？原料？场景？人物？）
- 怎么拍：（构图方式、光线、氛围）
- 注意：（广告法注意事项、品牌调性约束等）

**AI生图Prompt建议**：（如果需要AI生成画面）
- 中文Prompt��XXX
- English Prompt：XXX

**设计理由**：
（为什么这样写？为什么这样拍？结合消费者心理和转化逻辑解释。
这一步是最重要的 — 让设计师理解你的思考，而不只是拿到结果。）
```
