# 竞品真实链接自动抓取 SOP（全品类通用）

本 Skill 的竞品分析**强制要求 3-5 个带真实可点开商品链接的竞品**（详见 `detail-page-structure.md` 的「竞品分析框架」）。本文件规定"怎么自动抓到这些链接"，对**所有品类通用**——零食、洗护、日用品、小家电、纸巾、以及未来新增的任何品类，执行方式完全一致。

> 为什么必须"自动抓"：真实链接是详情页策划的信任地基。差异化机会、文案调性、视觉风格、可借鉴卖点，全部来自竞品真实详情页。没有真实链接，策划就是拍脑袋。

---

## 一、默认走法（WebSearch 优先）

1. **锁定品类与核心关键词**：如"手持风扇""吸盘碗""抽纸""冻干山楂条"。
2. **搜真实竞品**：用 WebSearch 搜 `[品牌]+[品类]+京东/天猫 商品`，优先拿 `item.jd.com` / `detail.tmall.com` / `item.taobao.com` 直链。
3. **每个竞品收集**（字段）：
   - 品牌名、产品名、价格区间
   - 月销量 / 累计评价数（量化数据）
   - 主打卖点（一句话）
   - **真实商品详情页直链**（最重要）
   - 视觉风格（配色、调性）
4. **至少 3 个必须有真实直链**；抓不到的标"链接待补充"，**绝不编造 URL**。

### 链接有效性硬性要求
- ⭐ 必须是商品详情页直链：`detail.tmall.com` / `item.jd.com` / `item.taobao.com`
- ❌ 禁止第三方排行榜 / 导购 / 聚合站（am10.com、smzdm.com、chjia.com、uland.taobao.com 等）
- ❌ 禁止用搜索关键词代替链接
- ❌ 禁止内容营销页（bk.taobao.com 知识库等）

---

## 二、兜底走法（WebSearch / WebFetch 故障时用子代理）

本会话 WebSearch / WebFetch **偶发"参数未传入"类故障**（主代理调用时报错，但子代理独立路径通常正常）。遇到这种情况：

1. **不要卡住**——竞品分析是阶段 2，不可跳过。
2. **不要编造链接**——编 URL 比没有链接更糟。
3. **改派一个 general-purpose 子代理兜底检索**，prompt 必须写清：
   - 要找哪些品类 / 关键词的真实竞品
   - 必须返回 `item.jd.com` / `detail.tmall.com` / `item.taobao.com` **直链**
   - 收集字段（品牌、价格、销量、卖点、视觉、链接）
   - **禁止编造 URL**；若工具也报错，明确回"网络工具不可用"
4. 子代理返回后，主代理照常做"普遍做法 + 差异化机会"分析；拿不到的标"链接待补充"。

> 经验：主代理 WebSearch 失败时，子代理的 WebSearch / WebFetch 往往仍能成功（独立调用路径）。这是已验证可用的兜底方案。

---

## 三、输出规范

- 竞品表必须含「产品链接」列，可点击访问。
- 总结"竞品普遍做法"与"我们的差异化机会"。
- 若用户要求"借鉴竞品卖点"：在逐屏策划里把可借鉴卖点标 **「借鉴」** 并注明来源（如"借鉴维达超韧打法"），与本品原卖点区分开。

---

## 四、适用说明

| 场景 | 处理 |
|------|------|
| 任何品类首次策划 | 阶段 2 都必须先跑本 SOP 抓真实竞品 |
| WebSearch 正常 | 主代理直接搜，拿直链 |
| WebSearch 故障 | 派子代理兜底，禁止编造 / 卡住 |
| 某一竞品无直链 | 标"链接待补充"，继续补其他 |
