# 零食视觉设计规则

## 品类视觉基因

### 适合的视觉关键词
自然、健康、年轻、品质

### 色彩方向
- **主色调**：暖黄、暖白、淡蓝、淡黄
- **原则**：根据产品包装颜色微调，保持整体协调
- **氛围**：温暖、自然、有食欲

### 摄影方式
- **光源**：自然光为主
- **构图偏好**：平视构图
- **常见手法**：食材结合产品、产品融入使用场景
- **场景风格**：居家简约风

### 字体方向
- **首选**：阿里巴巴普惠体（辨识度高、免费商用）
- **备选**：思源黑体、苹方
- **原则**：清晰易读，不要太花哨

### 版式特点
- 整齐划一
- 中英搭配（标题可用英文点缀提升品质感）
- 错落有致（大/中/小字体形成节奏）

### 绝对避免
- **廉价促销感** — 大红大紫、爆炸贴、价格跳水字体
- **过于冰冷** — 不要让零食看起来像药品

## 竞品视觉参考

### 三只松鼠
- **视觉特点**：年轻、有趣、强识别
- **优秀之处**：IP记忆强、消费者认知高
- **值得学习**：品牌人格化
- **不建议模仿**：完全模仿IP路线（需要有自己品牌特色）

### 良品铺子
- **视觉特点**：高级、干净、食品摄影优秀
- **优秀之处**：品质感强
- **值得学习**：品质表达方式

### 百草味
- **视觉特点**：自然、生活化

## 不同子品类视觉微调

### 儿童零食
- 色彩偏暖、柔和
- 场景：家庭、亲子
- 情绪：安心、温暖

### 肉脯类
- 色彩偏诱人（暖光、金棕色）
- 场景：休闲、聚会
- 情绪：满足、享受

### 果干类
- 色彩偏自然清新
- 场景：户外、日常
- 情绪：健康、轻盈
