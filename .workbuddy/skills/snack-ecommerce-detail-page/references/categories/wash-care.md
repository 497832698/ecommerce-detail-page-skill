# 洗护用品品类画像库

> 适用品类：洗发水、沐浴露、洗衣凝珠 / 洗衣液、身体乳、衣物护理等家庭清洁与个人护理品。
> 适用平台：淘宝、天猫、京东、拼多多、抖音。
> 定位：本文件是该品类的专属画像，AI 接到洗护类产品时优先加载此文件，再结合通用方法论策划。

---

## 一、品类本质（和零食的区别）

| 维度 | 零食 | 洗护用品 |
|------|------|---------|
| 购买驱动 | 欲望（想吃） | 解决问题（功能） |
| 决策理性度 | 中低，易被画面打动 | 高，成分党/功效党占比大 |
| 复购逻辑 | 好吃就回购 | 刚需消耗，信任建立后强复购 |
| 主要担忧 | 糖、添加剂 | 刺激、致敏、没效果、化学成分 |
| 情感落点 | 满足、宠爱 | 安心、专业、被照顾 |

**策划要点**：洗护详情页的说服逻辑是"我先证明你能解决问题，再让你喜欢我"，和零食的"先打动再说服"顺序相反。

## 二、消费者画像

### 画像 A：妈妈（家庭采购决策者）
- **购买者**：妈妈，25-40 岁，负责全家洗护采购
- **使用者**：全家（老公、孩子、自己）
- **核心需求**：温和不刺激（尤其宝宝/敏感肌）、成分安全、一瓶搞定、性价比
- **深层需求**："我选的东西不会伤害家人"——安全感优先于功效
- **最担心**：化学成分致敏、宝宝红屁股/湿疹、假滑冲不干净、香味刺鼻
- **决策关键词**：婴标、氨基酸、无香/低敏、0 添加、医研背书

### 画像 B：年轻女性（自用）
- **购买者 = 使用者**：18-35 岁，自己用
- **核心需求**：功效（控油/去屑/留香）、使用体验（泡沫/质地/颜值）、社交货币
- **深层需求**："用了显得我很会生活"——颜值和香味是社交谈资
- **最担心**：用了没效果、太便宜显廉价、香味不高级像廉价香精
- **决策关键词**：香氛、成分、颜值、博主同款、大牌平替

## 三、核心需求 × 担心 对照表

| 需求 | 对应担心 | 详情页要回答的问题 |
|------|---------|-------------------|
| 温和不刺激 | 致敏、红疹 | "成分表我看得懂吗？有刺激物吗？" |
| 真的有效 | 交了智商税 | "有没有前后对比 / 数据证明？" |
| 香味好闻 | 刺鼻香精 | "是什么香调？高级吗？" |
| 性价比 | 买贵了 | "大包装 / 替换装划不划算？" |
| 便利 | 麻烦 | "一瓶搞定还是要搭配一堆？" |

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 清爽水感蓝 `#4A90D9` / 植物绿 `#7DBE8E` + 大量留白 `#F7FBFC` | 蓝绿传递"干净、天然、安心"，留白显高级不廉价 |
| **摄影** | 水花飞溅、质地流动特写（乳液/凝珠）、植物原料（洋甘菊/氨基酸分子示意） | 洗护靠"质地感"建立品质认知，比产品静物更有说服力 |
| **字体** | 干净无衬线（如阿里巴巴普惠体），功效词用粗体放大 | 专业感，避免卡通化显廉价 |
| **整体调性** | 三个关键词：**干净、专业、安心** | 和零食的"诱人"调性区分开 |
| **避免** | 过度卡通（像儿童玩具）、医疗冷感（像药）、廉价促销大红大绿 | 卡通显廉价，医疗感吓人，促销感伤品牌 |

## 五、竞品常见打法（分析时重点看这些）

1. **成分党** — 主推氨基酸表活、无硅油、APG 表活，用成分表/分子结构图说话
2. **香氛赛道** — 对标大牌香调（祖玛珑平替、白茶调），用"留香 X 小时"建立记忆
3. **功效可视化** — 控油前后对比、去渍前后对比、留香时长测试
4. **婴标安全** — 0 岁可用、医研机构背书、无泪配方，主打"全家都能用"
5. **容量/性价比** — 大瓶装、替换装、组合装，用"每天不到 X 毛"算账

**差异化机会**：多数洗护竞品要么走"成分冷感"要么走"香氛感性"，很少把"真实使用场景 + 成分安全"结合得好。我们的机会是用生活化场景（浴室、洗衣）承载专业成分，让妈妈觉得"既专业又亲切"。

## 六、FBE 卖点转换示例

### 卖点：氨基酸表活
- **Feature**：采用氨基酸表面活性剂，非皂基
- **Consumer Truth**：妈妈怕刺激，宝宝娇嫩肌肤受不了皂基和硫酸盐
- **Benefit（人话）**：❌ "氨基酸温和配方" ✅ "宝宝红屁股也能用的洗感，洗完不干不假滑"
- **Emotion**：安心、被温柔对待
- **Visual**：宝宝洗澡笑脸 + 皂基 vs 氨基酸 成分对比图（左边"紧绷"，右边"水润"）

### 卖点：持久留香（微胶囊锁香）
- **Feature**：微胶囊香氛缓释技术
- **Consumer Truth**：年轻女性要"被夸香"，不是掩盖体味，是要高级感
- **Benefit（人话）**：❌ "留香持久" ✅ "洗完第二天发丝还有淡淡白茶香，像喷了淡香水"
- **Emotion**：高级、被关注、精致
- **Visual**：发丝/衣物特写 + 香气粒子飘散的视觉化（柔光、慢动作水感）

### 卖点：无添加 / 婴标
- **Feature**：0 香精 0 色素 0 防腐剂（或特定防腐体系），通过婴标
- **Consumer Truth**：妈妈翻成分表最怕看到"甲基异噻唑啉酮"这类刺激物
- **Benefit（人话）**：❌ "安全无刺激" ✅ "成分表你认识每一个字，宝宝啃玩具手也不怕"
- **Emotion**：彻底放心
- **Visual**：放大版成分表（高亮"你看得到的安全"）+ 宝宝啃手/玩玩具的生活画面

### 卖点：强去渍（洗衣凝珠）
- **Feature**：多腔凝珠，洗衣液+留香珠+护理液三合一
- **Consumer Truth**：妈妈烦"一瓶洗衣液洗不干净还要加别的"
- **Benefit（人话）**：❌ "强力去渍" ✅ "一颗搞定脏校服，领口发黄也能洗白"
- **Emotion**：省心、高效
- **Visual**：脏校服 vs 洗后校服 对比 + 凝珠遇水溶解的过程特写

## 七、逐屏策略差异（和零食详情页不同处）

| 屏序 | 零食打法 | 洗护打法（调整点） |
|------|---------|-------------------|
| 首屏 | 产品大图 + 诱人场景 | **先抛问题**（如"头油一天就塌？"）+ 产品 + 核心功效一句话 |
| 第二屏 | 痛点 + 竞品对比 | 痛点 + **成分/原理**为什么能解决（洗护更吃"懂原理"） |
| 第三屏 | 原料信任 | **成分表可视化 / 检测报告**（洗护信任核心在成分，不在原料长相） |
| 第四屏 | 工艺/口感强化欲望 | **功效前后对比图**（去油/去渍/留香时长，转化关键屏） |
| 第五屏 | 无添加证明 | 安全背书（婴标/医研/无刺激测试）+ 适用人群（宝宝/孕妇/敏感肌） |
| 第六屏 | 场景 + 规格 | 规格组合（大瓶+替换装）+ 回购理由（刚需消耗，强调囤货划算） |

**关键差异**：洗护的"信任屏"权重远高于零食——妈妈愿意为"成分安全"多花 30% 价格，但不愿为"好看"多花。所以成分/检测/适用人群要前置且突出。
