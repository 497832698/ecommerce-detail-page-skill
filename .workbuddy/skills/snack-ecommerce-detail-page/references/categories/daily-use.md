# 日用品品类画像库

> 适用品类：母婴用品（婴儿浴桶、洗脸盆、洗头帽、梳子、指甲钳等）、个护配饰（防晒帽）等"解决具体生活痛点"的实用型产品。
> 适用平台：淘宝、天猫、京东、拼多多、抖音、孩子王。
> 定位：本文件是该品类的专属画像，AI 接到日用品类产品时优先加载此文件，再结合通用方法论策划。

---

## 一、品类本质（和零食 / 洗护的区别）

日用品是**工具型 / 耐用品**——消费者买的不是"欲望"也不是"成分功效"，而是"帮我把一件麻烦事搞定"。

| 维度 | 零食 | 洗护用品 | 日用品 |
|------|------|---------|--------|
| 购买驱动 | 欲望（想吃） | 解决问题（功能） | 解决具体痛点（省心 / 省力 / 安全） |
| 决策理性度 | 中低，易被画面打动 | 高，成分党占比大 | 中高，看"是不是真的好用" |
| 复购逻辑 | 好吃就回购 | 刚需消耗，强复购 | **耐用品，复购低**——首单转化极重要 |
| 主要担忧 | 糖、添加剂 | 刺激、致敏、没效果 | 材质有毒、设计反人类、智商税（风小/不防晒） |
| 情感落点 | 满足、宠爱 | 安心、专业 | 省心、被照顾、有设计感 |

**策划要点**：
1. 日用品是**耐用品**，复购低 → 首单转化比什么都重要。详情页要在 3 秒内让人"一眼觉得必须买"，再用实测和材质打消最后顾虑。
2. 说服逻辑是"**我先让你看到痛点，再演示我怎么解决**"，比零食更依赖"演示"和"前后对比"，比洗护更依赖"人性化设计"而非"成分"。
3. 信任核心 = **材质安全（母婴级 / 食品级）+ 真实实测（续航 / UPF / 容量）+ 人性化设计演示**。

## 二、消费者画像

### 画像 A：妈妈（母婴类日用品决策者）
- **购买者**：妈妈，25-40 岁，负责宝宝用品采购
- **使用者**：宝宝（0-6 岁为主）
- **核心需求**：材质安全（可入口级 / 无异味）、设计省心（宝宝不抗拒）、好打理（易洗 / 可折叠）
- **深层需求**："我选的东西不会伤到宝宝，也别让我手忙脚乱"——安全感 + 轻松感优先
- **最担心**：塑料异味 / BPA 有毒、设计反人类（宝宝洗头哭闹、指甲剪出血）、占地方不好收纳
- **决策关键词**：母婴级、食品级 PP / TPE、圆头安全、可折叠、无异味

### 画像 B：年轻自用者（防晒帽 / 梳子等）
- **购买者 = 使用者**：18-35 岁，学生 / 上班族 / 户外党
- **核心需求**：真的有效（真防晒）、便携、颜值
- **深层需求**："用了显得我会生活"——颜值和便携是社交货币，防晒是刚需
- **最担心**：防晒无效、廉价塑料丑
- **决策关键词**：UPF50+、ins 风、可折叠、透气

## 三、核心需求 × 担心 对照表

| 需求 | 对应担心 | 详情页要回答的问题 |
|------|---------|-------------------|
| 材质安全 | 有毒 / 异味 / BPA | "是什么材质？有没有检测？宝宝能接触吗？" |
| 好用不麻烦 | 设计反人类、宝宝抗拒 | "怎么用的？宝宝愿意吗？有演示吗？" |
| 真的有效 | 交了智商税 | "续航 / UPF 有实测吗？有前后对比吗？" |
| 便携省空间 | 占地方 / 重 | "能折叠吗？多重？能挂能收吗？" |
| 颜值 | 廉价丑 | "有好看的颜色吗？拍照出片吗？" |

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 浅柔色系：奶白 `#F7F3EE` / 浅粉 `#F6D9D6` / 浅蓝 `#D6E8F0` + 少量点缀色（薄荷绿 / 鹅黄） | 母婴用品传递"干净、温柔、安全"，浅色显高级不廉价；避免大红大绿促销感 |
| **摄影** | ① 真实使用场景（浴室、户外、出行、床头）② 产品细节特写（材质纹理、折叠结构、圆头）③ 尺寸 / 容量对比（人手持、宝宝坐浴桶、帽子戴头上） | 日用品靠"场景 + 演示"建立信任，比单纯静物更有说服力 |
| **字体** | 干净无衬线（如阿里巴巴普惠体），功能参数用粗体放大（续航 / UPF） | 专业感，参数一眼可读 |
| **整体调性** | 三个关键词：**实用、贴心、有设计感** | 和零食的"诱人"、洗护的"专业安心"区分开 |
| **避免** | 廉价塑料感（强反光硬光）、过度医疗冷感、虚假参数大字报、过度卡通显幼稚 | 塑料感显廉价，虚假参数伤信任，卡通伤品牌 |
| **广告法** | 见下方「广告法合规」专节——日用品材质、防晒值、续航等宣称必须有依据，禁止绝对化用语 |

### 广告法合规（日用品重点）

- **材质宣称要有依据**：写"食品级 PP / 母婴级 TPE"需有检测或材质说明支撑；**禁止**说"可食用""能进微波炉/水煮消毒"除非确实耐温并标明温度。
- **防晒帽**：UPF 值必须真实（国标 UPF50+ 是上限标注），**禁止**虚假宣传防晒倍数；"全面防晒"需说明具体防晒面积（大檐 / 护颈 / 护脸）。
- **婴儿适用**：标注适用年龄（如 0 岁以上）要有依据；圆头安全设计可讲，但**禁止**写"绝不会剪伤 / 100% 安全"等绝对化承诺。
- **通用红线**：不使用"最 / 第一 / 顶级 / 全能 / 100%"等绝对化用语；对比竞品不指名道姓贬低。

## 五、竞品常见打法（分析时重点看这些）

1. **场景种草** — 浴室 / 出行 / 户外 / 床头真实场景，让人"对号入座"
2. **材质安全牌** — TPE / PP / 食品级，用检测报告或材质特写建立信任
3. **人性化设计** — 防进水洗头帽、折叠浴桶、圆头指甲钳，用"演示动图 / 前后对比"说话
4. **参数实测** — 续航时长、UPF 值，用数据建立靠谱感
5. **颜值经济** — ins 风、马卡龙色、莫兰迪色，靠"出片"做社交传播

**差异化机会**：多数日用品详情页要么只堆参数、要么只秀颜值，**很少把"痛点讲透 + 真实演示 + 材质背书"结合好**。我们的机会是用"真实场景演示（如洗头不进水的前后对比）+ 材质安全证明 + 实测数据"三位一体建立信任，让妈妈和年轻人都觉得"这东西真的能解决我的问题"。

## 六、FBE 卖点转换示例

### 卖点：婴儿折叠浴桶（可折叠 / 宝宝坐着洗）
- **Feature**：TPR 软胶可折叠，展开是坐浴桶，折起 8cm 厚
- **Consumer Truth**：妈妈怕浴桶占卫生间、硬塑料宝宝坐着硌、收纳没地方
- **Benefit（人话）**：❌ "可折叠便携浴桶" ✅ "用完一折塞门后，宝宝坐着洗不硌屁股，卫生间不再堆杂物"
- **Emotion**：省心、被照顾、清爽
- **Visual**：折叠前（占半平米）vs 折叠后（门后缝隙）对比 + 宝宝坐着笑的洗浴场景 + 材质特写（软胶纹理）

### 卖点：洗头帽防进水
- **Feature**：软硅胶护耳檐 + 可调节头围，挡水不进眼耳
- **Consumer Truth**：宝宝洗头就哭，因为水和泡沫进眼睛耳朵
- **Benefit（人话）**：❌ "宝宝洗头神器" ✅ "水顺着帽檐流走，宝宝洗头第一次没哭"
- **Emotion**：轻松、不焦虑、母慈子孝
- **Visual**：洗头前（宝宝皱眉要哭）vs 洗头后（宝宝笑着玩水）对比 + 水流沿帽檐流走的特写 + 调节头围演示

### 卖点：婴儿指甲钳（圆头安全）
- **Feature**：360° 圆头刃口 + 限位防夹肉 + 放大镜
- **Consumer Truth**：妈妈怕剪到宝宝嫩肉，普通指甲钳太锋利
- **Benefit（人话）**：❌ "安全婴儿指甲剪" ✅ "圆头贴着肉剪也不怕，第一次敢自己给宝宝剪指甲"
- **Emotion**：安心、敢下手
- **Visual**：圆头刃口特写（对比普通尖头）+ 妈妈给宝宝剪指甲的温柔场景 + 限位结构演示

### 卖点：防晒帽 UPF50+（大檐透气）
- **Feature**：UPF50+ 面料，12cm 大檐 + 护颈披肩，网眼透气
- **Consumer Truth**：妈妈 / 户外党怕晒黑晒伤，又怕帽子闷、遮不住后颈
- **Benefit（人话）**：❌ "防晒遮阳帽" ✅ "后颈也盖住，UPF50+ 实测不透光，网眼戴着不闷汗"
- **Emotion**：安心、清爽、好看
- **Visual**：帽檐遮光演示（脸 / 后颈在阴影里）+ UPF 检测报告特写 + 户外戴帽透气网眼特写

## 七、逐屏策略差异（和零食详情页不同处）

| 屏序 | 零食打法 | 日用品打法（调整点） |
|------|---------|-------------------|
| 首屏 | 产品大图 + 诱人场景 | **痛点场景 + 产品**（如"宝宝洗头总哭？"）+ 一句话核心利益 |
| 第二屏 | 痛点 + 竞品对比 | 痛点深挖 + **人性化设计演示**（怎么解决，动图 / 前后对比） |
| 第三屏 | 原料信任 | **材质安全证明**（母婴级 / 食品级 / 检测报告） |
| 第四屏 | 工艺 / 口感强化欲望 | **真实实测 / 功能演示**（折叠 / 防进水 / UPF 前后对比，转化关键屏） |
| 第五屏 | 无添加证明 | 适用人群 / 尺寸 / 场景（宝宝、出行、户外）+ 安全细节（圆头 / 调节） |
| 第六屏 | 场景 + 规格 | 规格（尺寸 / 颜色 / 续航）+ 组合装（如浴桶 + 洗头帽）+ 行动号召 |

**关键差异**：日用品是**耐用品、复购低**，所以首单转化权重最高——首屏要"一眼种草"，第四屏要靠"真实演示 + 实测"打消顾虑。材质安全和真实实测是信任的两根支柱，比零食的"好吃"、洗护的"成分"更依赖"看得见的证据"。
