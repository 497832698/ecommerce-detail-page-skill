# 小家电品类画像库

> 适用品类：便携风扇（手持小风扇、多功能数显风扇）、行车记录仪、监控摄像头等"电子消费品 / 小家电"。
> 适用平台：淘宝、天猫、京东、拼多多、抖音。
> 定位：本文件是该品类的专属画像，AI 接到小家电类产品时优先加载此文件，再结合通用方法论策划。

---

## 一、品类本质（和零食 / 洗护 / 日用品的区别）

小家电是**电子消费品**——消费者买的不是"欲望"也不是"材质"，而是"用科技解决一个具体问题"（降温 / 取证 / 看护）。

| 维度 | 零食 | 洗护 | 日用品 | 小家电 |
|------|------|------|--------|--------|
| 购买驱动 | 欲望 | 解决问题 | 解决痛点 | 功能 + 科技（电子消费品） |
| 决策理性度 | 中低 | 高 | 中高 | 高，参数党（清晰度 / 续航 / 风力） |
| 复购逻辑 | 好吃回购 | 刚需消耗 | 耐用品低复购 | **耐用品，复购极低，首单转化最关键** |
| 主要担忧 | 糖 / 添加 | 刺激 / 无效 | 材质 / 智商税 | 参数虚标、质量差、不好用、售后 |
| 情感落点 | 满足 | 安心 | 省心 | 安心（安全 / 看护）、省心（智能）、科技感 |

**策划要点**：
1. 小家电是**电子消费品**，复购极低 → 首单转化权重最高，靠"参数真实 + 场景实测"建立信任。
2. 说服逻辑是"**我先让你看到痛点（碰瓷 / 看不清 / 怕偷），再演示我怎么用科技解决**"，比日用品更吃"数据证据"（清晰度对比 / 夜视 / 续航）。
3. 信任核心 = **真实参数（分辨率 / 续航 / 风力）+ 场景实测（白天 vs 夜视 / 风力刻度）+ 品牌口碑 / 质保**。

## 二、消费者画像

### 画像 A：车主（行车记录仪）
- **购买者 / 使用者**：车主，25-50 岁
- **核心需求**：防碰瓷、事故取证、停车监控、夜视清晰
- **深层需求**："万一出事我有证据，不背锅"——安全感 + 掌控感
- **最担心**：关键时刻没录上、夜视糊、死机、安装复杂
- **决策关键词**：4K、夜视、停车监控、广角、循环录制

### 画像 B：家庭守护者（监控摄像头）
- **购买者**：家里有老人 / 孩子 / 宠物的家庭，25-45 岁
- **使用者**：全家（远程查看）
- **核心需求**：远程看护、防盗、清晰夜视、移动追踪、隐私安全
- **深层需求**："不在家也能看着家"——安心感
- **最担心**：画面糊、夜视差、掉线、隐私泄露
- **决策关键词**：2K / 3K 清晰、全彩夜视、AI 追踪、云存储 / 本地、加密

### 画像 C：年轻自用（风扇）
- **购买者 = 使用者**：18-35 岁，通勤 / 户外 / 学生
- **核心需求**：风大、便携、长续航、颜值
- **深层需求**："降温还要好看"——社交货币
- **最担心**：风小、续航虚标、廉价丑
- **决策关键词**：大风力、长续航、数显、可折叠、低噪

## 三、核心需求 × 担心 对照表

| 需求 | 对应担心 | 详情页要回答的问题 |
|------|---------|-------------------|
| 真实降温 / 清晰取证 | 风小 / 画面糊 / 夜视差 | "风力 / 分辨率有实测吗？白天和晚上差多少？" |
| 安全证据可靠 | 关键时刻掉链子 | "有紧急录像 / 停车监控 / 循环录制吗？" |
| 易用智能 | 连不上 / 装麻烦 | "APP / 安装怎么弄？演示一下" |
| 续航 / 供电 | 断电 / 虚标 | "续航多久？怎么供电？有实测吗？" |
| 隐私安全 | 泄露 / 被偷拍 | "数据加密吗？合规吗？" |

## 四、视觉规则

| 维度 | 方案 | 商业理由 |
|------|------|---------|
| **配色** | 科技深灰 `#2B2F33` / 黑 + 点缀蓝 `#3A7BD5` 或橙 `#FF7A45`；风扇可走清新浅色 | 电子消费品靠"科技 + 可靠"传递信任，深色调显专业不廉价 |
| **摄影** | ① 产品特写（屏 / 镜头 / 接口 / 数显）② 场景实拍（车内、家中、户外）③ 参数对比图（清晰度白天 vs 夜视、风力刻度、广角画面） | 小家电靠"数据 + 场景"建立可信，对比图最直观 |
| **字体** | 干净无衬线，参数（4K / 续航 / 分辨率）粗体放大 | 参数一眼可读，专业感 |
| **整体调性** | 三个关键词：**科技、可靠、清晰** | 和零食"诱人"、日用品"贴心"区分开 |
| **避免** | 虚假参数大字报、廉价塑料感、过度炫酷太空感 |
| **广告法** | 见下方「广告法合规」专节 |

### 广告法合规（小家电重点）

- **参数真实**：分辨率（4K / 2K）、夜视距离、续航、广角、风力要有依据，禁止虚标。
- **绝对化禁用**：不使用"最清晰 / 第一 / 全能 / 100% 安全"等绝对化用语。
- **监控隐私**：提示"合规使用，尊重他人隐私、征得同意"，不暗示偷拍 / 隐蔽用途。
- **风扇**：禁止"制冷 / 冰感"（只是吹风降温）；"静音"应写"低噪"，不写绝对静音。

## 五、竞品常见打法（分析时重点看这些）

1. **参数堆料** — 4K / 夜视 / 大广角 / 长续航，用参数表说话
2. **场景安全牌** — 碰瓷证据、看护老人孩子、防盗
3. **实测对比** — 清晰度白天 vs 夜视、风力档位、广角画面
4. **智能联动** — APP / 语音 / 云存储 / AI 追踪
5. **性价比** — 同参数比价格

**差异化机会**：多数只堆参数，少有"真实场景演示 + 痛点讲透"结合的。我们的机会是用"痛点场景 + 实测证据 + 易用演示"三位一体建立信任，让车主和家庭都觉得"这东西关键时刻真能顶用"。

## 六、FBE 卖点转换示例

### 卖点：手持 / 数显小风扇（便携长续航）
- **Feature**：5000mAh，数显电量 / 档位，可折叠手持 / 桌面两用
- **Consumer Truth**：通勤 / 户外热，要风大不重、能续航一天
- **Benefit（人话）**：❌ "大风力便携风扇" ✅ "通勤一天不用充电，风够大还不重，剩多少电数显一眼看清"
- **Emotion**：清爽、自由、省心
- **Visual**：女生单手持扇走户外 + 包里取出特写 + 数显屏电量特写 + 续航刻度（早出门→晚回家仍有电）

### 卖点：行车记录仪（4K + 夜视 + 停车监控）
- **Feature**：4K 分辨率 + 星光夜视 + 24h 停车监控 + 140° 广角 + 紧急录像
- **Consumer Truth**：车主怕碰瓷、事故说不清、晚上拍不清
- **Benefit（人话）**：❌ "高清行车记录仪" ✅ "晚上也拍得清，停着被撞自动录，出事不背锅"
- **Emotion**：安心、掌控、不慌
- **Visual**：白天 vs 夜视画面对比 + 停车监控触发演示 + 广角覆盖画面 + 紧急录像弹窗

### 卖点：监控摄像头（2K 全彩夜视 + AI 追踪）
- **Feature**：2K 清晰 + 全彩夜视 + AI 移动追踪 + 本地 / 云双存储 + 加密
- **Consumer Truth**：家庭怕老人 / 孩子 / 宠物没人看、夜里有情况看不清
- **Benefit（人话）**：❌ "高清监控摄像头" ✅ "晚上也全彩，宝宝翻身自动跟拍，不在家也能看着家"
- **Emotion**：安心、踏实
- **Visual**：白天 vs 夜视全彩对比 + AI 追踪框演示 + 手机远程查看界面 + 加密提示标

## 七、逐屏策略（小家电专属，屏数随产品浮动，禁止套固定模板）

小家电卖点密度差异极大（一支风扇可能 3 个卖点，一台记录仪可能 8 个），**屏数和文案没有固定值，必须由产品实际情况决定**。两条硬约束：
1. **屏数 = 本品卖点数 + 铺垫屏**（痛点 / 缺口 / 技术支撑 / 场景人群 / 规格质保 / CTA）。每屏只放大 1 个卖点；卖点多的产品自然 10+ 屏，卖点少的 6-8 屏也合理。
2. **主文案≤10字、副文案≤12字**（SKILL 铁律，所有屏适用，不随屏数放宽）。

### 屏数 / 文案怎么定（判断逻辑，必须走）
1. **收齐本品输入**：用户上传的**产品名 + 卖点清单**（阶段 0 / 阶段 1）——这是逐屏的"原料"。
2. **搜竞品真实详情页**：网上找 **3-5 家同品类竞品**，打开它们的真实详情页，重点记录：
   - 竞品打了**几屏**、每屏讲什么主题、顺序怎么排
   - 竞品**文案调性**（参数堆料 / 场景种草 / 实测对比）、**视觉风格**
   - 竞品**没讲或讲烂的点**（如只堆参数没演示、只秀颜值没背书）
3. **综合定屏**：`本品卖点数` + `竞品结构参考` + `差异化缺口` → 决定屏数与顺序：
   - 竞品都在讲的点 → 本品也要有，且用**实测 / 对比**打得更好
   - 竞品都没讲、本品独有的点 → **单独成屏**，做差异化突破口
   - 竞品讲烂的点 → 本品用"演示屏 / 背书屏"补位
4. **文案基于本品**：每屏主 / 副文案从本品卖点里提炼，不抄竞品、不套空话（如"大风力便携风扇"是废话，要写"通勤一天不充电，风够大还不重"）。

### 弹性屏序骨架（可增删，非固定）
| 屏序 | 作用 | 是否必选 |
|------|------|---------|
| 首屏 | 痛点 + 产品 + 核心一句话 | 必选 |
| 缺口屏 | 为什么普通 / 同类不行 | 建议 |
| 卖点屏 ×N | 每个核心卖点一屏（弱卖点可合并） | N = 本品卖点数 |
| 技术支撑屏 | 电机 / 原理背书（参数型卖点建议有） | 视卖点定 |
| 场景 + 人群屏 | 通勤 / 户外 / 学生 / 宝妈对号入座 | 必选 |
| 规格 + 认证 + 质保 | 参数表 / 质检 / 售后 | 必选 |
| 套装 + 行动号召 | 组合装 / 优惠 / CTA | 必选 |

> 行车记录仪、监控摄像头同理：屏数随卖点浮动，把"4K / 夜视 / 停车监控 / 广角 / AI 追踪 / 存储 / 加密"按本品实际有的逐屏放大，竞品详情页是结构参考而非模板。

### 手持小风扇·实例（基于某用户上传 8 卖点的弹性结果，非固定模板）
卖点：超级风力 / 五档精细风控 / 双 DC 无刷电机 / 续航狂魔 / 优雅随行 / 150g 超轻 / 4 色可选 / 人性化细节。本例因卖点多 → 12 屏；**若某风扇只有"风力 + 续航"2 卖点，则应为 6-7 屏**，不要硬凑。每屏主文案≤10字、副文案≤12字。

| 屏 | 主文案(≤10) | 副文案(≤12) | 画面 | 设计理由 |
|----|------------|------------|------|---------|
| 1 首屏 | 热到想融化 | 风小根本没用 | 女生通勤冒汗 + 产品特写 | 痛点开场，3 秒种草 |
| 2 缺口 | 普通扇不行 | 风小还短命 | 普通扇 vs 本扇对比 | 制造"必须换"的动机 |
| 3 超级风力 | 风够大才爽 | 直吹瞬间降温 | 发丝 / 纸屑被吹动 | 放大第一卖点 |
| 4 双电机 | 双电机才猛 | 无刷更稳更久 | 电机剖面 / 双机标识 | 技术背书风力可信 |
| 5 五档风控 | 五档刚刚好 | 风感随心调 | 1-5 档风感条动画 | 档位可视化，显专业 |
| 6 续航狂魔 | 一天不充电 | 续航实测为证 | 早出→晚归电量刻度 | 打消续航焦虑（转化屏） |
| 7 150g 超轻 | 轻到忘了带 | 比手机还轻 | 秤重 150g / 对比手机 | 轻量具象化 |
| 8 优雅随行 | 随手就走 | 包里桌面两用 | 包里取出 + 桌面立放 | 场景 + 颜值加分 |
| 9 4 色可选 | 总有一色爱 | 四色随心挑 | 4 色拼图 + 命名 | 降低选择成本 |
| 10 人性细节 | 细节很到位 | 数显折叠防滑 | 数显屏 / 折叠扣 / 按键 | 细节堆信任 |
| 11 人群 | 谁该带走它 | 通勤学生户外 | 多人群拼图 | 对号入座 |
| 12 行动 | 现在就带走 | 质保一年无忧 | 规格 + 套装 + CTA | 临门一脚 |

**关键差异**：小家电是**电子消费品，复购极低**，首单转化权重最高；信任靠"真实参数 + 场景实测 + 单卖点逐屏放大"。屏数与文案**不套模板**——以用户上传的产品名 / 卖点为原料，以网上竞品真实详情页为结构参考，动态生成。
