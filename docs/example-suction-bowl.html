竞品普遍做法

① 主讲故事集中在 注水保温 / 恒温 PPSU 内胆材质 吸管喝汤 / 自主进食 三件套 / 多功能；② 视觉多为浅柔母婴色或透明琥珀质感；③ 吸盘普遍只作为"防摔"一句话带过，很少把吸盘大小、吸力、防翻做实测演示。

我们的差异化机会

超大吸盘
竞品吸盘小、只说"防摔" → 本品讲"吸盘格外大、宝宝两只手扒不翻"，并做吸附实测。
分隔不串味
竞品多单碗或仅零食格 → 本品汤饭分区，"不串味"是喂饭刚需角度。
14°内扣防洒
几乎无人提盘口防洒 → 本品用内扣设计解决"舀汤洒一身"。
加厚不弯
薄碗一捏瘪是隐性痛点 → 本品单手端满碗汤不变形，做对比演示。

5整体视觉方向

配色
浅柔母婴色：奶白 #F7F3EE / 浅粉 #F6D9D6 / 浅蓝 #D6E8F0，点缀薄荷绿。温暖不廉价，避大红大绿促销感。
摄影
① 真实喂饭场景（餐椅 / 户外）② 细节特写（吸盘纹理、内扣壁、加厚壁）③ 对比演示（扒不翻 / 不洒 / 不变形）。
调性
三个词：实用 · 贴心 · 有设计感。避免塑料强反光的廉价感与过度卡通幼稚。
字体
干净无衬线（如阿里巴巴普惠体），功能参数（14° / 加厚 / 容量）用粗体放大。

6广告法合规提示

  • 材质宣称须有依据：写"食品级硅胶 / 食品级 PPSU"需有检测或材质说明支撑；禁止说"可食用""可微波炉水煮"除非确实耐温并标明温度。
  • 吸盘吸附力：用"吸附更牢 / 不易翻"，禁止写"吸力最强 / 绝对不翻 / 100% 防翻"。
  • 分隔防串味：用"减少串味 / 汤饭分开"，禁止写"完全不串味 / 绝对不混味"等绝对化。
  • 14°内扣防洒：可演示"减少外溢"，禁止写"绝不洒 / 100% 防洒"。
  • 适用年龄：标"6 月+ 建议"须有依据；不得暗示医疗或发育功效。
  • 通用红线：不使用"最 / 第一 / 顶级 / 全能"等绝对化用语；对比竞品不指名道姓贬低。
