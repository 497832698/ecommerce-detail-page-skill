竞品普遍做法

① 都打「好吸收」牌，A2 蛋白 / OPO / 益生元是高频词；② 进口品牌强调「原装进口、源乳」；③ 高端线堆「乳铁蛋白 + MFGM + HMO」成分矩阵；④ 详情页多用成分名词 + 检测报告截图建立信任。

我们的差异化机会

「北纬47°新鲜生牛乳 + 国产奶粉销量领先 + 100 种成长多维营养」是飞鹤独有叙事——把「新鲜奶源」做成视觉主线（竞品多讲成分、少讲奶源故事），并用「适合中国宝宝」的本土化信任替代「进口崇拜」，对妈妈群体的说服力更强。

⚠ 六、婴幼儿配方乳粉 · 广告法合规红线（必读）

  • 「吸收率达93%」：属数据/功效宣称，必须有第三方检测报告或临床实证支撑，否则不得擅自使用。建议改为「好吸收少负担」等合规表述，或在页面注明数据来源与检测机构。
  • 禁替代母乳暗示：不得使用「贴近母乳」「接近母乳」「以母乳为标准」「母乳黄金标准」等表述（竞品金领冠等常用，属违规风险）。
  • 禁功效绝对化：0–6 月婴儿奶粉广告全面禁止；较大婴儿/幼儿奶粉亦不得宣称「益智、增强抵抗力/免疫力、保护肠道、促进大脑发育、提高记忆力」等功效性用语，仅可作营养成分客观陈列。
  • 禁绝对化用语：不用「最、第一、顶级、100%、全能、唯一」等；「销量领先」须有依据，避免「销量第一」。
  • 「IMP蛋白」待核实：IMP 在奶粉语境不常见，疑为 HMO（母乳低聚糖）或某免疫蛋白笔误——按实际配方表核实名称后上稿，HMO 为合规营养素名。
  • 「100种营养」须核对：数字须与本品实际配料表/营养成分表一致，避免虚假宣传。
  • 禁止医疗机构/专家推荐：不得出现医生推荐、医疗机构背书。
  • 借鉴卖点标注：竞品独有专利成分（如某品牌 MFGM 特定表述）不得冒用，仅作「行业通用成分」陈列并标注借鉴来源。
