本品"食品级保湿因子"是平价面巾纸里的稀缺卖点——直接对标 babycare 乳霜纸的"润"体验，但价格带更低。把"云柔感 + 食品级保湿 + 呵护敏感肌"三位一体做成主题，在平价带里形成"擦鼻子也不红"的独特定位，避开和维达拼"韧"、和洁柔拼"压花"的红海。

四、FBE 卖点转换（4 核心卖点）

① 100%原生木浆

Feature：100%原生木浆，非回收浆。
Consumer Truth：怕纸巾掺回收浆、有荧光剂，擦嘴擦脸不安全。
Benefit（人话）：100%原生木浆 → 每张都来自新木浆，擦嘴擦脸都安心，宝宝也能用
Emotion：纯净、安心　Visual：木浆原料特写 + 回收浆(暗黄)vs本品(洁白)对比 + 原料检测报告

② 食品级保湿因子

Feature：添加食品级保湿因子，纸面带润感。
Consumer Truth：普通纸干硬，擦鼻子擦红了、敏感肌越擦越痒。
Benefit（人话）：添加保湿因子 → 擦鼻涕也不红，像沾了层润，敏感鼻也能天天用
Emotion：温柔、被呵护　Visual：纸面润泽微距 + 鼻子擦试前后(红→不红)对比 + 保湿因子示意

③ 温和无刺激

Feature：无香精、无荧光剂、无刺激添加（结合借鉴"无荧光剂"）。
Consumer Truth：香味纸巾熏得慌，荧光剂怕长期用。
Benefit（人话）：温和无刺激 → 没香味没荧光剂，凑近闻也安心，敏感肌不怕
Emotion：干净、安心　Visual："无添加"标签特写 + 紫外灯下不变色演示 + 裸脸凑近纸

④ 呵护敏感肌

Feature：通过敏感肌适用测试 / 母婴可用（结合借鉴"母婴可用"）。
Consumer Truth：敏感肌/宝妈怕纸巾诱发泛红。
Benefit（人话）：呵护敏感肌 → 敏感肌和宝宝脸都能天天擦，红痒少了
Emotion：被照顾、专业　Visual：敏感肌测试报告 + 宝妈给宝宝擦脸场景 + 婴儿脸颊特写

八、广告法合规提示

食品级保湿因子："食品级"仅指该保湿成分为食品级原料，禁止说"可食用/能吃/入口无害"；需有成分依据支撑。
呵护敏感肌 / 母婴可用：可说"适用/温和不刺激"，禁止说"治疗/改善/修复敏感肌""医用级"等医疗宣称；"婴儿可用"需有适用依据，不写绝对化。
100%原生木浆：需有原料证明（非回收浆），不写"最纯净"。
无荧光剂 / 无添加：需检测支持；不写"最安全/零刺激"。
通用红线：不用"最/第一/顶级/100%/全能"；借鉴卖点（湿水不易破/不掉屑）须真实，不夸大。
